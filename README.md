# Amazon Sales SQL Analysis

## 📌 Project Overview

This project analyzes Amazon sales data using MySQL and SQL to identify sales trends, customer behavior, product performance, and geographical sales patterns.

The analysis is performed on a dataset containing 100,000 sales records.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- GitHub

## 📊 Dataset

The dataset contains information related to:

- Order details
- Customer information
- Product details
- Category and Brand
- Quantity and Pricing
- Discounts, Tax and Shipping Cost
- Payment Method
- Order Status
- City, State and Country
- Seller information

## 🔍 SQL Analysis Performed

### Basic Analysis
- Total number of orders
- Total revenue
- Total quantity sold
- Average order value
- Number of unique customers

### Product & Category Analysis
- Category-wise sales
- Brand-wise sales
- Top 5 best-selling products by quantity
- Top 5 products by revenue
- Categories with sales above ₹1 crore
- Top 3 products within each category

### Customer Analysis
- Customers with total spending above ₹50,000
- Top 3 customers in each city by total spending

### Geographical Analysis
- City-wise sales
- Highest-sales city in each state

### Time-Based Analysis
- Monthly sales trend
- Monthly revenue and order count
- Highest revenue-generating month
